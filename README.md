# MBTI性格测试网站

一个简洁易用的MBTI性格测试网站，支持性别选择和详细的性格分析。

## 功能特点

- 🧑‍🤝‍👩 支持男生/女生性别选择
- 📋 20道精心设计的测试题目
- 🎯 准确的MBTI性格类型分析
- 📊 详细的维度得分显示
- 💡 个性化的成长建议和职业推荐
- 📱 响应式设计，支持移动设备
- 💾 自动保存测试进度
- 🔄 可重新测试

## 在线体验

部署到以下平台之一：
- [GitHub Pages](#github-pages-部署)
- [Netlify](#netlify-部署)
- [Vercel](#vercel-部署)

## 本地运行

1. 克隆或下载项目
2. 直接用浏览器打开 `public/index.html` 文件

## 部署指南

### GitHub Pages 部署

1. 创建GitHub仓库
2. 上传项目文件
3. 在仓库设置中启用GitHub Pages
4. 选择 `main` 分支的 `/ (root)` 或 `public` 文件夹

### Netlify 部署

1. 访问 [Netlify](https://netlify.com)
2. 拖拽 `public` 文件夹到Netlify部署区域
3. 自动获得部署链接

### Vercel 部署

1. 访问 [Vercel](https://vercel.com)
2. 连接GitHub仓库或直接上传文件
3. 自动部署并获得链接
